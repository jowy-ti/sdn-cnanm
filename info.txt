// Global packages
frr            (Debian/Ubuntu: apt-get install frr, daemons in /usr/lib/frr)
               (Fedora:          dnf install frr,     daemons in /usr/libexec/frr)
mininet        (PyPI, installed into .venv by requirements.txt -- not apt)

## SETUP

    ./scripts/setup.sh          # idempotent; apt/dnf-aware; --dry-run supported

It performs the machine-level steps that used to be manual:

    sudo systemctl disable --now frr   # the lab starts its own FRR instances
    sudo usermod -aG frrvty root       # ipmininet validates configs as root

and writes /etc/sudoers.d/net_topology for the current checkout:

    <user> ALL=(ALL) NOPASSWD: <repo>/.venv/bin/python <repo>/src/net_topology_yaml.py
    <user> ALL=(ALL) NOPASSWD: <repo>/.venv/bin/python -m ipmininet.clean

## DAILY

    make check    # parse topologies/srv6.yaml (no root)
    make doctor   # preflight checks
    make run      # start the lab (sudo); exit at the mininet> prompt
    make clean    # remove leftovers after a crash/Ctrl-C (sudo)

## VM CREATION

Create or recreate the ubuntu2204 VM from scratch (clean, no repo installed):

    ./scripts/create-ubuntu2204-vm.sh          # interactive (will prompt before destroying)
    ./scripts/create-ubuntu2204-vm.sh --force  # no prompt

The script uses the existing cloud image and seed at /var/lib/libvirt/ (jammy-server-cloudimg-amd64.img + cloud-init/ubuntu2204).

## VIRSH QUICK GUIDE (ubuntu2204 VM)

All virsh commands on this host should use the system URI (the VM lives in qemu:///system).

    export LIBVIRT_DEFAULT_URI=qemu:///system  # optional, makes commands shorter

### Power / state
    virsh -c qemu:///system list --all          # list VMs (running/shut off)
    virsh -c qemu:///system start ubuntu2204    # boot the VM
    virsh -c qemu:///system shutdown ubuntu2204 # graceful shutdown (ACPI)
    virsh -c qemu:///system reboot ubuntu2204   # reboot guest
    virsh -c qemu:///system destroy ubuntu2204  # hard power off (last resort)
    virsh -c qemu:///system domstate ubuntu2204 # show current state

### Connect / inspect
    ssh ubuntu2204                             # quick SSH (see ~/.ssh/config)
    ssh -i ~/.ssh/github ubuntu@192.168.122.220
    virsh -c qemu:///system console ubuntu2204 # serial console (Ctrl+] to exit)
    virsh -c qemu:///system domifaddr ubuntu2204 --source agent  # get guest IP
    virsh -c qemu:///system dominfo ubuntu2204 # resources, autostart, UUID
    virsh -c qemu:///system domblklist ubuntu2204 # disks attached

### Snapshots
    virsh -c qemu:///system snapshot-list ubuntu2204
    virsh -c qemu:///system snapshot-create-as ubuntu2204 before-upgrade
    virsh -c qemu:///system snapshot-revert ubuntu2204 before-upgrade
    virsh -c qemu:///system snapshot-delete ubuntu2204 before-upgrade

### Autostart / network
    virsh -c qemu:///system autostart ubuntu2204        # start VM on host boot
    virsh -c qemu:///system autostart --disable ubuntu2204
    virsh -c qemu:///system net-list --all               # check virbr0/default network

### Tips
- Default URI on this host is qemu:///session - always use qemu:///system for ubuntu2204.
- If SSH times out, wait a few seconds or check the IP with domifaddr --source agent.
- Prefer `shutdown` over `destroy`. Use `destroy` only if the guest is unresponsive.
- Current IP: 192.168.122.220 (user: ubuntu, key: ~/.ssh/github)
